# 가대 LOST & FOUND

가톨릭대학교 교내 분실물·습득물 게시판 목업입니다.

## 실행 방법
1. Node.js LTS를 설치합니다.
2. 터미널에서 이 폴더로 이동합니다.
3. `npm install`
4. `npm run dev`
5. 브라우저에서 http://localhost:3000 접속

## Vercel 배포
GitHub에 프로젝트를 올린 뒤 Vercel에서 해당 저장소를 Import하고 Deploy를 누르면 됩니다.

## 데이터 안내
게시글은 현재 브라우저의 localStorage에 저장됩니다. 다른 기기나 사용자에게 자동 공유되지 않습니다.
샘플 데이터는 시연용 가상 데이터입니다.
